# MUD RING 3D — прототип 2.5D на Godot 4

Мобильная игра, выросшая из веб-версии [MUD RING](../mudring): вода, тахометр с зелёной зоной, лебёдка,
масстарт 6 квадроциклов, 2 круга по кольцу, «Экстрим» с резиной; въезд в воду на газу — глиссер.
Логика — вдоль трассы, картинка — в 3D.

## Запуск

```bash
brew install --cask godot          # Godot 4.7+
godot --path . -e                  # открыть в редакторе (F5 — запуск)
godot --path .                     # сразу запустить игру
```

Управление: держать палец на экране / пробел / ↑ — газ; кнопка «ЛЕБЁДКА», тап по столбику или `E` — трос.

Автопилот для проверок (как `__auto` в веб-версии), скриншоты в папку на заданных секундах заезда:

```bash
godot --headless --path . -- --auto=extreme:assassinator --quit   # заезд без окна, итог в консоль
godot --path . -- --auto=normal --shot=/путь/к/папке --quit       # скриншоты shot_00…06.png
```

## Сборка под Android

Без Gradle, отладочная подпись, только arm64. Один раз: Android SDK (command-line tools: `platform-tools`,
`build-tools;35.0.1`, `platforms;android-35`), JDK 17, шаблоны экспорта Godot 4.7.2, пути к SDK и JDK в
настройках редактора (Editor Settings → Export → Android).

```bash
tools/android.sh            # → build/mudring3d.apk
tools/android.sh install    # + установка на телефон по USB и запуск
```

На телефоне: «Настройки → О телефоне → Номер сборки» 7 раз → «Для разработчиков» → «Отладка по USB».
Пакет `com.mudring.ring3d` — перед публикацией в Google Play выбрать окончательный (потом не меняется).

## Модель квадроцикла

Строится кодом в Blender 4.5 (`brew install --cask blender`), без ручного моделирования:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/blender/atv.py -- models/atv.glb [папка_рендеров]
```

Объекты: `Body`, `Wheel_FL/FR/RL/RR` (начало на оси), `Rider` (начало в тазу — для наклона). Цвет — в вершинах,
код перекраски — в UV.x: 1 — свой цвет, 0 — краска корпуса, 0.25 — акцент, 0.5 — джерси, 0.75 — шлем.
Размеры совпадают с физикой (база 1.45 м, радиус колеса 0.44 м). Из папки рендеров — превью с 4 ракурсов.

## Кольцо

Трасса — «стадион» (`scripts/ring.gd`): прямая 0 → поворот → прямая 1 (в обратную сторону) → поворот, радиус
поворотов 16 м. Прямые — это верхняя и нижняя дорожки трассы `core.gd` (ванны, стенки с лебёдкой); повороты —
ровная грязь с пределом скорости 9 м/с. Старт и финиш — одна линия, 2 круга.
Камера стоит снаружи кольца, на экране квадроцикл всегда едет слева направо.

## Ручная правка моделей в Blender

Исходники: `models/src/atv.blend` (квадроцикл) и `models/src/env.blend` (окружение). Правка:

1. Открыть `.blend` в Blender, поправить. Имена объектов не менять (игра ищет `Body`, `Wheel_FL/FR/RL/RR`,
   `Rider`, ассеты окружения — по именам). Начало координат колёс — на оси, гонщика — в тазу.
2. Цвета — режим Vertex Paint (слой `Col`). Чтобы видеть их во вьюпорте: Solid → Color → Attribute.
   Детали, которые игра перекрашивает (квадроцикл), задаются UV-слоем `Code`: u = 0 корпус, 0.25 акцент,
   0.5 джерси, 0.75 шлем, 1 — свой цвет. Новым деталям копируйте код с соседних.
3. Сохранить и выгрузить: вкладка Scripting → Open → `tools/blender/export.py` → Run Script
   (или `Blender -b models/src/atv.blend -P tools/blender/export.py`). Получится `models/atv.glb`.
4. Пересобрать игру (Godot подхватит новый `.glb` сам).

Внимание: генераторы `tools/blender/atv.py` и `env.py` перезаписывают и `.blend`, и `.glb` — после ручной правки
их не запускать (или сначала скопировать свой `.blend`). Упрощённые копии квадроцикла для ботов (`*_LOD1`, `*_LOD2`)
делает только генератор: после ручной правки `Body`/`Rider`/`Wheel_FL` их нужно обновить (Decimate) или удалить —
тогда боты будут с полной моделью.

## Окружение

По фото соревнований (`example/`, в репозиторий не входит). Ассеты строятся кодом в Blender:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/blender/env.py -- models/env.glb [папка_превью]
```

Расстановка — `scripts/env.gd`; плотность травы зависит от качества (низкое/среднее/высокое).

## Звук

Синтезируется на лету (`scripts/synth.gd`), без аудиофайлов, как в веб-версии. Послушать без игры:

```bash
godot --headless --path . -s tests/sound_dump.gd && open .tmp/sound_demo.wav
```

Сценарий демо: холостые → светофор и перегазовки → разгон (рядом бот) → вода → отсечка → заглох → лебёдка → финиш.

## Проверка после правок

```bash
GODOT=godot tests/smoke.sh     # ядро + заезды на автопилоте на всех уровнях доходят до конца
```

Проект развивается самостоятельно от веб-версии MUD RING (физика и правила уже отличаются).

## Структура

```
project.godot        рендерер Mobile, альбомная ориентация, тач
scenes/main.tscn     корневая сцена (всё остальное собирается кодом)
scripts/core.gd      ядро: трасса, физика, лебёдка, ИИ ботов (без узлов, работает headless)
scripts/ring.gd      кольцо-«стадион»: две прямые с ваннами + повороты; «участок + x» → точка, направление, нормаль
scripts/race.gd      заезд: масстарт, 2 круга по кольцу, места, сходы, итоги (из game.js)
scripts/main.gd      3D-мир: рельеф кольца, земля, вода, столбики, арка «СТАРТ · ФИНИШ», камера снаружи кольца, ввод, экраны
scripts/quad.gd      квадроцикл: модель models/atv.glb (запасной вариант — из примитивов), перекраска ботов, грязь, брызги
models/atv.glb       квадроцикл с гонщиком (~10 тыс. треугольников), генерируется tools/blender/atv.py
scripts/env.gd       окружение: трава, ленты на кольях, березняк и лес, флаги, шатры, зрители (MultiMesh кусками по 40 м)
models/env.glb       ассеты окружения, генерируются tools/blender/env.py
shaders/ground.gdshader  земля: мокрая грязь колеи с колеями от колёс, трава с сухими проплешинами
shaders/env.gdshader качание травы, флагов и крон на ветру, цвет курток зрителей
shaders/atv.gdshader перекраска по коду в UV и налипающая грязь (шум в вершинах — дёшево для мобильных)
scripts/synth.gd     звук без файлов: мотор (такты, хрип, отсечка, глохнет), бот рядом, бульканье, лебёдка, эффекты
scripts/sound.gd     проигрывание synth.gd через AudioStreamGenerator
scripts/hud.gd       HUD: время, место, тахометр с зелёной зоной, перегрев, светофор, сообщения
shaders/water.gdshader  мутная вода: волны, блики, круги и пена вокруг игрока
tests/sound_dump.gd  демо звука по сценарию заезда → .tmp/sound_demo.wav + замер скорости синтеза
tests/               smoke.sh — проверка после правок; sim.gd — сценарий ядра
```

## Чего пока нет (следующие этапы)

- Модели: квадроцикл, гонщик, окружение из Blender или ассетов. Звук пока синтезирован — позже можно заменить
  записью настоящего мотора по оборотам (тот же интерфейс synth.gd: rpm, load, water, over).
- Вопрос по регламенту перед Экстримом, рекорды и общий сервер (`/ring/scores`), имя игрока.
- Экспорт: iOS (Xcode, подпись) и Android (SDK, keystore), настройки качества для слабых телефонов.
